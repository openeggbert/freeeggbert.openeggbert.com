Object Types (TYPE_*)

Moving game objects — enemies, items, effects, vehicles, and bombs — are identified by TYPE_* constants (values 1–203). Defined in include/def.hpp. Objects are tracked in MoveObject structs and managed by CDecor via the moveObject[200] array in src/decmove.cpp.
