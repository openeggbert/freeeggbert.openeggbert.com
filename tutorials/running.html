Running Free Eggbert

How to run the game after building. For build instructions, see Building.

⚠️
Free Eggbert is a work in progress. Many gameplay behaviors are incomplete or may not match the original game. Audio and multiplayer are particularly incomplete.

Game Assets (Required)

Before running, you must supply game assets from an original copy of Speedy Eggbert 2 (Speedy Blupi II). The assets are not redistributable. Copy them into the gamefiles/ directory: 

gamefiles/
├── DATA/        ← world levels, demo files, config
├── IMAGE08/     ← 8-bit sprite sheets
├── IMAGE16/     ← 16-bit sprite sheets (default)
└── SOUND/       ← music and sound effects

See Assets & Files for the expected directory contents.

Desktop (Linux / macOS / Windows)

Run the built executable from the repository root:

# Linux / macOS
./build/bin/SPEEDY_BLUPI_WINDOWS

# Windows
build\bin\Release\SPEEDY_BLUPI_WINDOWS.exe

The executable must be run from the repository root so that it can find gamefiles/. Running from a different working directory will cause asset loading to fail.

Configuration

Runtime settings are read from gamefiles/DATA/config.def. Key settings:

KeyValuesDescription
FullScreen0 / 1Windowed (0) or fullscreen (1)
TrueColorBack8 / 16Color depth for background sprites
TrueColorDecor8 / 16Color depth for decor sprites (default 16)
SpeedRate1–2Game speed multiplier (1=normal, 2=fast)

Edit the file with any text editor. Changes take effect on next launch. See Configuration for all keys.

Web (Emscripten)

After the Emscripten build completes:

emrun cmake-build-web/bin/SPEEDY_BLUPI_WINDOWS.html

emrun starts a local HTTP server and opens the page in your browser. Opening the .html file directly (via file://) will not work due to browser restrictions on WebAssembly + filesystem access.

Persistent saves (web)

Save data is stored in IndexedDB via Emscripten's IDBFS, mounted at /save. Clearing browser site data resets saves to preloaded defaults. To manually manage saves from the browser console: 

// Flush /save directory to IndexedDB
Module.ccall('FreeEggbert_ExportPersistentData', null, [], []);

// Restore /save from IndexedDB
Module.ccall('FreeEggbert_ImportPersistentData', null, [], []);

These functions are defined in src/web_persistence.cpp.

Common Issues

SymptomLikely causeFix
Black screen on launch Missing or misplaced gamefiles/ Ensure all four subdirectories (DATA, IMAGE08, IMAGE16, SOUND) are present
No audio Audio system incomplete or assets missing Known issue; check gamefiles/SOUND/ exists
Game crashes immediately Asset loading failure Run from the repository root directory, not from inside build/bin/
Fullscreen issues Double CPixmap::Create() call — known decompilation issue Try windowed mode: set FullScreen=0 in config.def
Web: blank page File opened via file:// instead of HTTP Use emrun to serve via HTTP
