Building Free Eggbert

This tutorial walks through building Free Eggbert from source on each supported platform. For a reference overview, see Build & Compile.

Prerequisites (All Platforms)

  • Git — for cloning and submodules
  • CMake 3.20+
  • C++20 compiler (GCC 11+, Clang 13+, MSVC 2022+)
  • Game assets — must be obtained from an original copy of Speedy Eggbert 2; place them in gamefiles/ as described in Assets & Files

Linux / macOS

Step 1 — Clone the repository

git clone <repo-url> free-eggbert
cd free-eggbert
git submodule update --init --recursive

Step 2 — Configure with CMake

cmake -S . -B build -DSPEEDY_BLUPI_BACKEND=FREEDIRECT

This uses the vendored SDL submodule by default. To use system-installed SDL instead, add -DFREE_USE_SYSTEM_SDL=ON.

Step 3 — Build

cmake --build build -j$(nproc)

Step 4 — Place assets and run

cp -r /path/to/original/gamefiles ./gamefiles
./build/bin/SPEEDY_BLUPI_WINDOWS

Clean rebuild

rm -rf build
cmake -S . -B build -DSPEEDY_BLUPI_BACKEND=FREEDIRECT
cmake --build build -j$(nproc)

Windows (Visual Studio 2022)

Prerequisites

  • Visual Studio 2022 with C++ workload
  • CMake (bundled with VS 2022 or standalone)

Step 1 — Clone

git clone <repo-url> free-eggbert
cd free-eggbert
git submodule update --init --recursive

Step 2 — Configure

cmake -S . -B build -G "Visual Studio 17 2022" -A x64 ^
      -DSPEEDY_BLUPI_BACKEND=FREEDIRECT

Step 3 — Build (command line or IDE)

cmake --build build --config Release

Or open build/SPEEDY_BLUPI_WINDOWS.sln in Visual Studio and build from the IDE.

ℹ️
If the build fails with COM header errors, ensure the Windows SDK is installed with the correct COM headers. See Build & Compile — Visual Studio.

Emscripten (WebAssembly)

Prerequisites

  • Emscripten SDK (emsdk) installed and activated

Step 1 — Activate emsdk

source /path/to/emsdk/emsdk_env.sh

Step 2 — Configure and build

emcmake cmake -S . -B cmake-build-web -DCMAKE_BUILD_TYPE=Debug
cmake --build cmake-build-web -j

Game assets from gamefiles/ are preloaded into the Emscripten virtual filesystem at build time — no manual copying is required for the web build.

Step 3 — Run locally

emrun cmake-build-web/bin/SPEEDY_BLUPI_WINDOWS.html
ℹ️
Save data is stored in IndexedDB via Emscripten's IDBFS, mounted at /save. To flush saves from the browser console: Module.ccall('FreeEggbert_ExportPersistentData', null, [], []);

Android

Android build support is present under android/. See Platform Support — Android for the complete step-by-step guide.
